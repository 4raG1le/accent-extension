Скачайте архив с расширением или клонируйте репозиторий:

1) git clone https://github.com/your-username/stress-extension.git
2) Откройте Chrome и перейдите по адресу chrome://extensions/
3) Включите "Режим разработчика" (переключатель в правом верхнем углу)
4) Нажмите кнопку "Загрузить распакованное расширение"
5) Выберите папку с расширением

Готово! Иконка расширения появится в панели инструментов


📖 Как пользоваться

1) ажмите на иконку расширения в панели инструментов браузера
2) Нажмите кнопку "Выбрать ударение"
3) Выберите фразу - кликните на любое слово в предложении (подсветится желтым)
4) Выберите слово - кликните на нужное слово в выделенной фразе
5) Выберите ударение - в появившемся окне нажмите на вариант с нужной ударной гласной
6) Выберите режим применения:
7) Нажмите на конкретный вариант - ударение применится только к этому слову (оранжевая подсветка)
8) Нажмите "Применить ко всем" - ударение применится ко всем таким словам на странице (зеленая подсветка)
