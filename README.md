Скачайте архив с расширением или клонируйте репозиторий:

git clone https://github.com/your-username/stress-extension.git
Откройте Chrome и перейдите по адресу chrome://extensions/

Включите "Режим разработчика" (переключатель в правом верхнем углу)

Нажмите кнопку "Загрузить распакованное расширение"

Выберите папку с расширением

Готово! Иконка расширения появится в панели инструментов


📖 Как пользоваться

Нажмите на иконку расширения в панели инструментов браузера

Нажмите кнопку "Выбрать ударение"

Выберите фразу - кликните на любое слово в предложении (подсветится желтым)

Выберите слово - кликните на нужное слово в выделенной фразе

Выберите ударение - в появившемся окне нажмите на вариант с нужной ударной гласной

Выберите режим применения:

Нажмите на конкретный вариант - ударение применится только к этому слову (оранжевая подсветка)

Нажмите "Применить ко всем" - ударение применится ко всем таким словам на странице (зеленая подсветка)
